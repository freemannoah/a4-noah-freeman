## ATAssist - https://a4-noahfreeman.onrender.com/

ATAssist is a tool to help log your time on the clock. Sick of Automated Time & Attendance (ATA) being confusing? Use this thing. In order to use the app, you must login with a username in the upper left box, you can use a new name or an existing one. Then input the date and time and click the 'clock in' or 'clock out' buttons to log the time event. A user is able to login by entering a correct username and password pair. If an unclaimed username is entered with a password, a new user will be created. I implemented basic password authentication for simplicity. When logged in, user statistics will display in the upper right, and all time entries for your user will appear at the bottom of the screen. When a user is logged in, you can edit or delete that user's time entries my clicking the corresponding button in the table, editing  or deleting the values, and clicking confirm.

When completing a4, I used React, Vite, and Material UI to enhance to product and development process. I made use of React components and hooks  as well as Material UI elements to enhance the application. Using React hooks like useEffect allows the client to better update and maintain state information. I also segmented the app into four components that app.tsx ties together, this promotes shorter files and easier to read code. In my opinion the development experience was improved by these new technologies primarily through the ability to dynamically update the page when files are saved, without having to restart it.
